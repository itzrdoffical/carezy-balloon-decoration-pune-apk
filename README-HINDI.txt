CAREZY BALLOON DECORATION ANDROID APK PROJECT

Yeh Android WebView app aapki Carezy website ko app ke roop mein kholta hai.
Internet connection zaroori hai. Yeh source project hai, APK abhi compile nahi hua.

GitHub upload:
1. ZIP ko extract karein.
2. GitHub repository itzrdoffical/carezy-balloon-decoration-pune kholein.
3. Add file > Upload files par jaakar extracted android folder aur .github folder upload karein.
4. Commit changes karein.
5. Actions tab kholein. "Build Carezy Android APK" workflow run hone dein.
6. Green success hone par workflow run kholein > Artifacts > Carezy-Balloon-Decoration-APK download karein.
7. ZIP artifact extract karke app-debug.apk phone mein install karein.

Note: Yeh debug APK hai jo Android phone mein install/test ho sakta hai. Public distribution/Play Store ke liye baad mein signed release APK banana hoga.
